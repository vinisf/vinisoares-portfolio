# Capturas reais do ViniFit

Adicione screenshots reais do aplicativo Android neste diretório em PNG, JPG ou WebP. Sugestão: `01-treinos.webp`, `02-treino-em-andamento.webp`, `03-historico.webp`, `04-evolucao.webp`.

O portfólio importa os arquivos automaticamente no próximo build, em ordem alfabética. Os cards exibem a primeira captura e o modal permite navegar pelas demais, em uma moldura de smartphone. Use imagens verticais e revise os dados pessoais antes de adicioná-las. Enquanto não houver imagens, a área indica explicitamente que as capturas ainda não estão disponíveis; nenhuma tela do app é simulada.
